# Устаревшие скомпилированные тесты

[English](../stale-compiled-tests.md) | Русский | [简体中文](../zh/stale-compiled-tests.md)

Перед вызовом `node:test` `fwa` проверяет, что каждому найденному
скомпилированному тесту соответствует исходный TypeScript-тест и что исходник
не новее результата сборки.

Это блокирует осиротевшие файлы и обнаруживает распространённый случай, когда
исходный тест изменился после создания скомпилированного JavaScript. Проверка
основана на существовании файлов и времени их изменения; она не доказывает, что
скомпилированное содержимое соответствует исходнику.

## Исходный тест существует

Если исходник существует и скомпилированный файл не старее, тест можно
запускать:

```text
src/feature/example.test.ts
dist/feature/example.test.js
```

## Исходный тест удалён

Если исходника больше нет, выполнение завершается ошибкой без удаления файлов:

```text
Stale compiled tests without source found.

Run with --prune to remove them:
- dist/feature/old.test.js
```

При использовании `--prune` скомпилированный тест удаляется:

```text
Pruned stale compiled tests without source:
- dist/feature/old.test.js
```

Режим `--prune` включается явно, поскольку удаление файлов из `outDir` изменяет
состояние файловой системы. По умолчанию `fwa` завершает работу с ошибкой и
сообщает, какие файлы следует удалить.

Если `--prune` удаляет все найденные тесты, удаление всё равно считается
успешным. После него `fwa` сообщает, что доступных для запуска тестов не осталось,
и устанавливает `process.exitCode = 1`.

Для безопасности `outDir` должен быть отдельным каталогом внутри выбранного
корня проекта. Удаление запрещено, если `outDir` совпадает с корнем проекта,
разрешается за его пределами или является символической ссылкой на внешний
каталог.

До удаления проверяется весь список тестов. Если другой скомпилированный тест
устарел относительно своего исходника, `fwa` не удаляет ни одного файла и
завершает работу с предложением пересобрать проект.

## Исходный тест новее

Если исходный тест новее скомпилированного, выполнение завершается ошибкой:

```text
Compiled tests are older than source tests.

Rebuild before npm test:
- dist/feature/example.test.js (source: src/feature/example.test.ts)
```

Перед запуском тестов пересоберите проект:

```sh
npm run build
npm test
```

## Границы проверки актуальности

Для каждого исходного и скомпилированного теста сравнивается время изменения.
Ошибка возникает, только если время изменения исходника позднее времени
изменения результата сборки.

Это защита от распространённых устаревших артефактов, а не доказательство
актуальности всей сборки. `fwa` не хеширует содержимое файлов и не проверяет,
были ли пересобраны остальные исходники проекта. Всегда запускайте сборку
проекта перед `fwa`.

## Источник истины

Проверка устаревших скомпилированных тестов реализована в следующих файлах:

- `src/infrastructure/test-files.ts`
- `src/application/run-suite.ts`

Этот документ описывает поведение. Точные диагностические сообщения и правила
удаления определяются кодом и тестами.
